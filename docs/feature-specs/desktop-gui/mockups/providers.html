Providers

OpenAI-compatible model endpoints. A persona names a provider and a model; the provider names the environment variable its key lives in.
openrouter
https://openrouter.ai/api/v1key envOPENROUTER_API_KEY
Key set
fireworks
https://api.fireworks.ai/inference/v1key envFIREWORKS_API_KEY
Key set
nvidia
https://integrate.api.nvidia.com/v1key envNVIDIA_API_KEY
No key
Keys are stored in your OS secret store and exposed to a review as the named environment variable. They are never written to a config file or committed. For CI reviews, set the same secret in the repo's GitHub Actions secrets.
